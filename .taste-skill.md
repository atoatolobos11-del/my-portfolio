# Taste-Skill Design Guidelines (Installed Locally)

This file contains design taste improvements applied to this portfolio based on leonxlnx/taste-skill principles. 

## Core Design Principles Applied

### Spacing & Layout
- Generous vertical padding between sections (py-20 md:py-32 lg:py-48)
- Ultra-wide containers for headings to allow text to flow naturally
- Prevent horizontal scroll with overflow-x-hidden
- Cinematic chapter-like separation between sections

### Typography
- Bold, high-impact headings with proper tracking
- Improved line heights and letter spacing
- Focus on readability and visual hierarchy
- Avoid cramming text into narrow containers

### Visual Polish
- Subtler, more professional animations (not overdone)
- Enhanced hover states with smooth transitions (700ms ease-out)
- Improved glow effects and shadows
- Better use of negative space

### Grid & Cards
- Intentional card layouts (fewer, higher quality)
- Smooth hover lift effects (translateY -10px)
- Consistent border radius and spacing
- Professional dark card designs

### Motion
- Fade-in + slide-up animations with viewport triggers
- Staggered animations for lists/grids
- Smooth section transitions
- Subtly animated profile image with breathing glow

## Implementation Notes
- All animations use Framer Motion (already installed)
- Tailwind CSS for styling
- Focus on premium, award-worthy design
- Maintain professional aesthetic without emojis
- Orange (#FF7200) as primary accent color
- Dark theme (#0D0D0D, #111111, #1A1A1A)
